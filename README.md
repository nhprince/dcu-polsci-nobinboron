# নবীনবরণ ২০২৫–২৬ — রাষ্ট্রবিজ্ঞান বিভাগ

ঢাকা সেন্ট্রাল ইউনিভার্সিটি (সরকারি শহীদ সোহরাওয়ার্দী কলেজ ক্যাম্পাস)-এর রাষ্ট্রবিজ্ঞান বিভাগের ২০২৫–২৬ শিক্ষাবর্ষের নবীনবরণ অনুষ্ঠানের নিবন্ধন ফর্ম ও অ্যাডমিন প্যানেল।

**Cloudflare Pages + Functions + D1** ভিত্তিক সম্পূর্ণ ফ্রি-টিয়ার ও সিঙ্গেল-অরিজিন ওয়েব অ্যাপ্লিকেশন।

## প্রধান সুবিধাসমূহ

- **পাবলিক নিবন্ধন ফর্ম (`/`)** — ৬ ধাপের মোবাইল-বান্ধব বাংলা ফর্ম:
  - ব্যক্তিগত তথ্য (শিক্ষার্থীর পূর্ণ নাম, পিতার নাম, মাতার নাম)
  - একাডেমিক তথ্য (শিক্ষাবর্ষ, শিক্ষার্থী আইডি / রোল নম্বর)
  - যোগাযোগ ও ঠিকানা (মোবাইল, ই-মেইল, বর্তমান ও স্থায়ী ঠিকানা + একই ঠিকানা টগল)
  - অনুষ্ঠানে অংশগ্রহণ (হ্যাঁ / না), বিশেষ প্রতিভা/পরিবেশনা ও পরামর্শ/প্রত্যাশা
  - সরাসরি ক্যামেরা ভিউফাইন্ডার (WebRTC) ও ফাইল আপলোডের মাধ্যমে প্রোফাইল ছবি ও আইডি/ভর্তি রশিদ (ব্রাউজারেই স্বয়ংক্রিয় সাইজ সমন্বয়)
  - চূড়ান্ত তথ্য যাচাই ও নিশ্চয়ন চেকবক্স
- **অ্যাডমিন প্যানেল (`/admin.html`)**:
  - পাসওয়ার্ড সুরক্ষিত ড্যাশবোর্ড (HMAC-SHA256 সেশন কুকি)
  - পরিসংখ্যান কার্ড ও চার্ট (মোট নিবন্ধন, অংশগ্রহণকারী, বিশেষ প্রতিভা, গত ৭ দিন)
  - সার্চ, ফিল্টার (অংশগ্রহণ, প্রতিভা, ই-মেইল অবস্থা) ও সর্টিং
  - বিস্তারিত দেখা, তথ্য ও ছবি সম্পাদনা, মুছে ফেলা
  - একক ও একত্রে (Bulk) নিশ্চিতকরণ ই-মেইল পাঠানো (Resend API)
  - UTF-8 BOM সহ CSV ডাউনলোড (Excel-এ বাংলা সঠিকভাবে খোলার জন্য + ছবির লিংক)

## লোকাল রান ও ডিপ্লয়মেন্ট

```bash
npm install
npm run db:init:local
npm run dev
```

অ্যাডমিন প্যানেল ও ই-মেইল কনফিগারেশনের জন্য Cloudflare Pages Secrets সেট করুন:

```bash
npx wrangler pages secret put ADMIN_PASSWORD
npx wrangler pages secret put SESSION_SECRET
# ঐচ্ছিক (নিশ্চিতকরণ ই-মেইলের জন্য):
npx wrangler pages secret put RESEND_API_KEY
```
